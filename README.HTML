Getting Started

Prerequisites

  • Docker Desktop 4.x+
  • Node.js 20+
  • Python 3.12+

Required env vars

  • ANTHROPIC_API_KEY — Claude integration
  • STRIPE_SECRET_KEY — billing
  • LABELGRID_API_KEY — distribution
  • JWT_PRIVATE_KEY_PATH — production RS256

Docker (recommended)

# Clone
git clone https://github.com/ThatGuy-Productions/RAIN-V6-AI-AUDIO-TRANSFORMATION-MASTERING-AND-DISTRIBUTION-INFRUSTRUCTURE.git
cd RAIN-V6-AI-AUDIO-TRANSFORMATION-MASTERING-AND-DISTRIBUTION-INFRUSTRUCTURE

# Configure
cp .env.example .env
# Edit .env — set ANTHROPIC_API_KEY, STRIPE_SECRET_KEY, etc.

# Start full stack (PostgreSQL 18 + Valkey 9.0 + backend + frontend)
docker compose up --build -d

# Verify
curl http://localhost:8000/health

Local development

# Backend
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000

# Frontend  (separate terminal)
cd frontend
npm install
npm run dev

GPU worker (separation)

# Requires CUDA 12+ and SEPARATION_ENABLED=true in .env
docker compose -f docker-compose.gpu.yml up -d worker

Architecture Rules

These constraints are immutable. See CLAUDE.md for the full specification.

  • [1]
    Local-First Processing
    RainDSP WASM is the sole render engine. Audio never reaches S3 on the free path. Free renders live in WASM memory and are discarded on session close.
  • [2]
    Dual-Path Architecture
    Preview (Web Audio API, 32-bit) and Render (RainDSP, 64-bit) are always separate codepaths. Never merge them.
  • [3]
    Multi-Tenant Isolation
    Every DB query includes WHERE user_id = $user_id. Row-Level Security enabled on all tables. No exceptions.
  • [4]
    K-Weighting Sign Convention
    y = b0·x + b1·x₁ + b2·x₂ − a1·y₁ − a2·y₂. a1 stored negative, subtracted. This is the ITU-R BS.1770-4 convention — never change it.
  • [5]
    NORMALIZATION_VALIDATED Gate
    RAIN_NORMALIZATION_VALIDATED=true → gate OPEN → RainNet inference active. Gate is closed by default; must be explicitly opened after validation. Sign-off authority: Phil Bölke.
  • [6]
    WASM Binary Integrity
    rain_dsp_wasm_hash verified at session start via SHA-256. Mismatch = RAIN-E304, render blocked. Set RAIN_EXPECTED_WASM_HASH in production.
  • [7]
    Provenance Before Output
    Output hash verified against RAIN-CERT before session marked complete. Mismatch = RAIN-E305. Unsigned cert = RAIN-E306. No exceptions in production.
