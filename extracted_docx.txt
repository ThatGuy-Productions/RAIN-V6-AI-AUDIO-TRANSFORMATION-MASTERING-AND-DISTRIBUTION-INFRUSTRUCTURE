10. Three-Layer Compliance Stack
EU AI Act Article 50 — All three layers MUST be applied to every render output before 2 August 2026.
Layer 1
C2PA v2.2 Manifest (CBOR-encoded, embedded in WAV/MP3)
AI involvement assertion: "This audio was processed by AI mastering system"
ProcessingParams fingerprint: SHA-256(canonical JSON of ProcessingParams)
RAIN-CERT hash reference (Ed25519-signed provenance)
Layer 2
AudioSeal Watermark (Meta, 16-bit invisible)
Embeds: RAIN session ID + timestamp
Survives: MP3 compression, re-encoding, format conversion
Verify via: facebook/audioseal detector
Layer 3
RAIN-CERT Ed25519 Provenance Certificate
session_id, input_hash, output_hash, processing_params_hash, wasm_binary_hash, timestamp, signature, signer
RAIN-E305: output hash mismatch → render corrupt, rollback immediately
RAIN-E306: signature invalid → signing key compromised, audit immediately
Layer 3b
DDEX ERN 4.3.2 AI Disclosure
ai_involvement_type: processing | generation | enhancement
ai_model_name: RainNet v2 (or Custom LoRA: {lora_id})

Enterprise only. Specialises RainNet v2 for specific genres, artist styles, or loudness preferences.
Upload 100–1,000 reference tracks (WAV or FLAC)

RainNet base outputs 46-param predictions

Auto-deployed when status = 'ready' — backend injects LoRA path into ONNX session
Accuracy expectation: ±0.3 dB integrated LUFS vs. reference, per genre.
